# Kick Video Downloader & Summarizer

This tool downloads videos or clips from Kick using `yt-dlp`, transcribes them locally via OpenAI's `Whisper`, and uses a local instance of `Ollama` to generate a detailed summary.

## Tool Requirements & Installation

While some dependencies can be installed via Python's package manager, this script relies heavily on external system tools to process audio and generate the summary.

### 1. Python Dependencies
First, install the required Python packages. *(Note: Make sure `requests` is installed for the Ollama connection, as it might not be in your initial requirements text).*
```bash
pip install -r requirements.txt
pip install requests
```

### 2. FFmpeg (Crucial System Dependency)
Both `yt-dlp` (for trimming video sections) and `whisper` (for extracting audio and transcribing) **require** the FFmpeg backend to be installed on your system.
*(Note: the `ffmpeg` package in requirements.txt is just a Python wrapper. You still need the actual system executable).*

**On Windows:**
1. Download a pre-compiled Windows zip file from [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) or [BtbN](https://github.com/BtbN/FFmpeg-Builds/releases).
2. Extract the folder to a permanent location (e.g., `C:\ffmpeg`).
3. Add the `C:\ffmpeg\bin` directory to your system's `PATH` environment variable.
4. Open a new terminal and type `ffmpeg -version` to verify it's installed correctly.

**On macOS / Linux:**
```bash
# macOS
brew install ffmpeg

# Ubuntu/Debian
sudo apt update && sudo apt install ffmpeg
```

### 3. Ollama (Local AI Summarizer)
This script uses a local Large Language Model via Ollama to crunch the transcript into a detailed summary. Based on the script's default, it looks for the `minimax-m2.7:cloud` model.

1. Download and install [Ollama](https://ollama.com/download) for your operating system.
2. Ensure the Ollama app is running in the background.
3. Open a terminal and test the required model before running the script:
   ```bash
   ollama run minimax-m2.7:cloud
   ```
   *(If you want to use local model, such as `llama3`, run `ollama pull llama3` instead and specify it via the script arguments).*

## How to Use the Script

Run the tool via the command line using `python kick_tool.py <URL>`. 

### Basic Usage
To download a video, transcribe it from start to finish, and summarize it:
```bash
python kick_tool.py "https://kick.com/sneako/videos/video-id-here"
```

### Advanced Usage (Clipping & Vocabulary)
You can trim the video to specific timestamps to save time. You can also provide a custom vocabulary constraint to help Whisper correctly spell names or niche terms.

**Windows PowerShell Example:**
```powershell
python kick_tool.py "https://kick.com/sneako/videos/video-id-here" `
    --start "01:02:23" `
    --end "02:20:00" `
    --vocabulary "Host is Sneako, speaking with guest Professor Jiang" `
    --model "minimax-m2.7:cloud"
```

### Available Arguments
- `url`: The Kick video URL (required).
- `--start`: Start time for trimming (e.g., `00:01:30`).
- `--end`: End time for trimming (e.g., `00:02:45`). **Note:** Both `--start` and `--end` must be provided to clip the video correctly.
- `--output`: Name of the temporary audio file (default: `audio.mp3`).
- `--vocabulary`: Specific names or context to help Whisper transcribe better (This is also fed to Ollama to establish prompt context).
- `--model`: The local Ollama model to use for the API call (default: `minimax-m2.7:cloud`).
- `--no-transcript`: Skip the Whisper transcription phase completely.

### Output Files
After a successful run, the tool will produce the following files in the same directory:
- `audio.mp3`: The downloaded and extracted audio clip.
- `transcript.txt`: The text file containing the entire video/clip transcript with timestamps.
- `summary.txt`: The final Markdown formatted summary of the interaction generated by Ollama.
